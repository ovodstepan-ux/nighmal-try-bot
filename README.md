# Nighmal Try Bot — бесплатный вариант

Канал: @nighmal
Шанс успеха: 40%

## Render
Используется Free Web Service, а не Background Worker.

Build Command:
`pip install -r requirements.txt`

Start Command:
`python bot.py`

Environment Variable:
`BOT_TOKEN` = токен от @BotFather

Бот должен быть администратором канала @nighmal, чтобы проверять подписку.

Важно: бесплатный Web Service Render может засыпать после периода без входящего HTTP-трафика и имеет ограничения бесплатного плана. Для Telegram long polling это означает, что бесплатный вариант не гарантирует работу 24/7.
