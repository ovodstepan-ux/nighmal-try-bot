# Telegram /try bot

Канал: @nighmal
Шанс успеха: 40%

## Запуск
1. Загрузите эти файлы в GitHub.
2. Создайте Worker на Render.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python bot.py`
5. Добавьте Environment Variable:
   - Key: `BOT_TOKEN`
   - Value: токен от @BotFather
6. Добавьте бота администратором канала @nighmal, чтобы он мог проверять подписку.

Не публикуйте токен бота в GitHub.
